\section{Grade 10: Discrete Probability Distributions}\label{sec:grade10-term1-overview}

\subsection{Learning Strand}\label{sec:grade10-term1-strand}

Complex and non-standard problems solving.

\subsection{Learning Objective}\label{sec:grade10-term1-objective}

Measure expected monetary value of investments.

\subsection{Assessment Criteria}\label{sec:grade10-term1-criteria}

\begin{enumerate}
	\item Describes random variables considering their characteristics.
	\item Interprets simple and cumulative probability distributions.
	\item Explains what a Bernoulli random variable is through examples.
	\item Identifies a random experiment that follows a binomial distribution.
	\item Calculates probabilities where a binomial or negative binomial variable is identified.
	\item Establishes cases in which the random variable is geometric.
	\item Evaluates probabilities in cases that follow a Poisson distribution.
	\item Compares the expected value and variance of the discrete distributions.
	\item Deconstructs the concept of an investment portfolio.
	\item Measures expected monetary value of investments.
\end{enumerate}

\subsection{Key Topics}\label{sec:grade10-term1-topics}

\begin{itemize}
	\item Random variable.
	\item Probability distributions.
	\item Cumulative probability distribution.
	\item Bernoulli random variable.
	\item Combinations.
	\item Binomial distribution.
	\item Negative binomial or Pascal distribution.
	\item Geometric distribution.
	\item Mean and variance of discrete distributions.
	\item Investment portfolio.
	\item Expected value.
\end{itemize}
